퍼스트 체대입시 한체대반

⚙️ 초기 연결 설정이 필요합니다

이 페이지는 Firebase(무료)를 데이터 저장소로 사용합니다. 아래 자리표시자를 선생님의 실제 Firebase 프로젝트 값으로 바꿔야 학생들과 실시간으로 기록을 주고받을 수 있어요. (Claude에게 값을 알려주시면 대신 채워드립니다.)

  1. 1console.firebase.google.com 접속 → 새 프로젝트 만들기 (무료)
  2. 2왼쪽 메뉴 Firestore Database → 데이터베이스 만들기 → 테스트 모드로 시작
  3. 3프로젝트 설정(⚙️) → 내 앱 → 웹 앱 추가 → 나오는 firebaseConfig 값을 복사
  4. 4그 값을 Claude 대화창에 붙여넣어 주시면 이 페이지에 연결해 드립니다.
